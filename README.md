# Introduction
This is a small react application that creates a cv based on the entered input from the user. While I believe that it would be simpler to do this using vanilla javascript, I made this project just so that I can learn the basics of React, such as hooks, states, and unidirectional data flow. 

Perhaps my favorite part of building this project is creating the individual components, as it kinda gives a similar feeling to building with LEGO bricks.
